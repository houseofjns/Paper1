TOPIC 1

Digital Devices · ဒစ်ဂျစ်တယ်စက်ပစ္စည်းများ

1.1 Types of digital devices

Mainframe computers handle large, complex processing for many users. Microprocessors are embedded in devices such as washing machines. Desktop and laptop computers are personal computers; tablets and smartphones are portable devices. Specialist phones may focus on a particular function. Cameras, camcorders, games consoles, media players, home entertainment systems and navigation aids (GPS) are also digital devices.

Multifunctional means one device performs several functions. Convergence means devices increasingly combine similar functions, e.g. a smartphone combines camera, GPS, media player and communication tools.

မြန်မာ: Mainframe သည် အသုံးပြုသူများစွာအတွက် ကြီးမားသောဒေတာများကို စီမံသည်။ Microprocessor ကို အဝတ်လျှော်စက်ကဲ့သို့ ပစ္စည်းများအတွင်း ထည့်သွင်းထားနိုင်သည်။ Multifunctional ဆိုသည်မှာ စက်တစ်လုံးက လုပ်ဆောင်ချက်များစွာ လုပ်နိုင်ခြင်း၊ Convergence ဆိုသည်မှာ စက်အမျိုးမျိုး၏ လုပ်ဆောင်ချက်များ တစ်စက်တည်းတွင် ပေါင်းစည်းလာခြင်းဖြစ်သည်။

1.2 Features used to compare devices

  • Portability: ease of carrying/moving.
  • Performance: speed and ability to handle demanding tasks.
  • Storage: capacity for files and applications.
  • User interface: how the user interacts with the device.
  • Connectivity: available wired/wireless connections.
  • Media support: ability to handle images, audio and video.
  • Energy consumption: power use and battery life.
  • Expansion capability: ability to add memory, storage or peripherals.
  • Security features: passwords, biometrics, encryption.
မြန်မာ: Device တစ်ခုရွေးရာတွင် သယ်ဆောင်ရလွယ်ကူမှု၊ စွမ်းဆောင်ရည်၊ Storage ပမာဏ၊ အသုံးပြုရလွယ်ကူမှု၊ ချိတ်ဆက်နိုင်မှု၊ ဘက်ထရီအသုံးခံမှုနှင့် လုံခြုံရေးတို့ကို လိုအပ်ချက်နှင့် ကိုက်ညီအောင် နှိုင်းယှဉ်ပါ။

1.3 Software

System software runs/manages the computer; examples include operating systems and utilities. Application software helps users complete tasks: word processing, spreadsheets, presentations, web authoring, image/sound editing, control and project-management software. Free/open-source software allows access to source code under its licence; proprietary software is controlled by its owner and subject to licence restrictions. Communication software enables remote access and exchange of messages/files. Updates fix bugs, improve security and add features, but can cause incompatibility or data loss if interrupted; back up first.

OS roles include single-user/network operation, memory and resource management, security and print spooling (placing print jobs in a queue).

မြန်မာ: System software သည် ကွန်ပျူတာစနစ်ကို စီမံခန့်ခွဲပြီး Application software သည် အသုံးပြုသူ၏ အလုပ်များကို လုပ်ဆောင်ပေးသည်။ Software update သည် လုံခြုံရေးပြဿနာနှင့် ချို့ယွင်းချက်များကို ပြင်ဆင်နိုင်သော်လည်း မအောင်မြင်ပါက ဖိုင်ပျက်စီးခြင်း သို့မဟုတ် မကိုက်ညီမှု ဖြစ်နိုင်သည်။

1.4 Input and output peripherals

Input: keyboard, mouse, trackball, joystick, graphics tablet, scanner, digital camera, webcam, microphone, touchscreen, OMR (reads shaded marks), OCR (converts printed text to editable text), barcode reader, biometric scanner, magnetic-stripe reader, chip-and-PIN reader and sensors. Output: monitor (screen size/resolution), inkjet printer (good colour/photo output), laser printer (fast text printing), 3D printer (physical objects), plotter (large precise drawings), projector, speakers and control devices.

မြန်မာ: Input device က ဒေတာကို ကွန်ပျူတာထဲသို့ ထည့်သွင်းပေးသည်။ Output device က ရလဒ်ကို ပြသ/ထုတ်ပေးသည်။ OMR သည် အမှတ်ခြစ်ထားသောနေရာကို ဖတ်ပြီး OCR သည် ပုံနှိပ်စာသားကို စာသားဒေတာအဖြစ် ပြောင်းပေးသည်။

1.5 Storage devices and media

A storage device reads/writes data; storage media is the material on which data is stored. HDD uses magnetic rotating platters; high capacity and low cost per GB but moving parts make it slower and more vulnerable to shock. SSD uses flash memory, has no moving parts and is fast, quiet and shock-resistant, but often costs more per GB. Optical media include CD, DVD and Blu-ray. Flash drives/cards are portable. Magnetic tape is often used for backup/archive. Internal storage is fitted inside a device; external storage connects separately. R means write-once; R/W means rewritable. Units: bit, byte (8 bits), KiB (1024 bytes), MiB, GiB, TiB.

မြန်မာ: HDD သည် လည်ပတ်နေသော သံလိုက်ပြားများကို အသုံးပြုသည်။ SSD သည် Flash memory ကို အသုံးပြုပြီး ပိုမြန်ကာ လှုပ်ခါမှုဒဏ်ခံနိုင်သည်။ R သည် တစ်ကြိမ်သာရေးနိုင်ခြင်း၊ R/W သည် ဖျက်ပြီး ပြန်ရေးနိုင်ခြင်းဖြစ်သည်။ 1 byte = 8 bits၊ 1 KiB = 1024 bytes ဖြစ်သည်။

1.6 Memory · 1.7 Processor · 1.8 System selection

RAM is volatile read/write working memory; more RAM lets more/larger applications run smoothly. ROM is non-volatile and stores firmware/start-up instructions. Flash memory is non-volatile and can be electrically erased/reprogrammed; used in SSDs, USB drives and memory cards. The CPU executes instructions and processes data; clock speed is measured in Hz, commonly GHz. A faster clock can help, but performance also depends on cores, architecture and workload. Select devices/software by matching the scenario, budget, accessibility and required peripherals. Accessibility settings include screen magnification, screen readers, high contrast, captions, speech input and alternative input devices.

မြန်မာ: RAM သည် လက်ရှိအသုံးပြုနေသော Program များအတွက် ယာယီမှတ်ဉာဏ်ဖြစ်ပြီး မီးပိတ်လျှင် ပျောက်သည်။ ROM သည် မီးပိတ်သော်လည်း မပျောက်ဘဲ Firmware ကို သိမ်းထားသည်။ CPU သည် Instruction များကို လုပ်ဆောင်ပြီး Clock speed ကို Hz/GHz ဖြင့် တိုင်းတာသည်။
Deeper understanding, examples & exam application

Choosing a device: match the user to the task

Do not recommend a device only because it is popular. Identify the user's task, location, required software, input/output needs, storage, budget and accessibility needs. For example, a graphic designer may need a high-resolution display, accurate colour, powerful processor and large SSD; a travelling student may prioritise low weight, battery life, camera, Wi-Fi and a comfortable way to type.

Memory and storage are different

RAM is temporary working space used while programs are running. Storage (HDD/SSD/flash) keeps files and applications when power is off. A computer can have large storage but still feel slow if it has insufficient RAM. ROM is non-volatile and commonly stores firmware used during start-up.

Input and output: choose the right technology

OMR is suitable for reading shaded multiple-choice forms; OCR converts printed characters into editable text; a barcode reader identifies coded products; a biometric reader checks a physical characteristic. Inkjet printers are useful for colour photographs and low-volume home printing, while laser printers are often suitable for fast, high-volume text documents. A plotter is designed for large, precise technical drawings.

စာမေးပွဲတွင် Device ရွေးချယ်ခိုင်းပါက လူအသုံးပြုသူ၏ လိုအပ်ချက်၊ သယ်ဆောင်ရမည့်အခြေအနေ၊ Software၊ စျေးနှုန်း၊ Battery၊ Storage၊ Accessibility တို့ကို ချိတ်ဆက်ရှင်းပြပါ။ RAM သည် Program လည်ပတ်နေစဉ် ယာယီအသုံးပြုသည့် Memory ဖြစ်ပြီး SSD/HDD သည် မီးပိတ်ပြီးနောက်လည်း ဖိုင်များကို သိမ်းထားနိုင်သော Storage ဖြစ်သည်။ OMR သည် အမှတ်ခြစ်ထားသည့် အဖြေလွှာဖတ်ရန်၊ OCR သည် ပုံနှိပ်စာသားကို ပြင်ဆင်နိုင်သော စာသားအဖြစ် ပြောင်းရန် အသုံးပြုသည်။
TOPIC 2

Connectivity · ချိတ်ဆက်ဆက်သွယ်မှု

2.1 Digital communication methods

Devices communicate using satellite, broadcast (TV/radio), wired cable or wireless methods. Networks include LAN (local area), WAN (wide area), PAN (personal area); tethering shares a mobile device's internet connection with another device. Wireless technologies: Wi-Fi (local network access), Bluetooth (short-range device-to-device), GPS (satellite positioning), 3G/4G cellular data, infrared (short-range line-of-sight) and NFC (very short-range tap communication, e.g. contactless payment).

Wi-Fi vs Bluetooth: Wi-Fi generally connects devices to a network/internet with higher throughput and greater range; Bluetooth is designed for short-range, low-power connections such as headphones and keyboards.

မြန်မာ: LAN သည် အိမ်/ကျောင်း/ရုံးလို နေရာကျဉ်းတွင် အသုံးပြုသည်။ WAN သည် မြို့/နိုင်ငံအနှံ့ ကွန်ရက်များကို ချိတ်ဆက်သည်။ PAN သည် လူတစ်ဦး၏ အနီးအနားရှိ စက်များကို ချိတ်ဆက်သည်။ Wi-Fi သည် Network ချိတ်ရန်၊ Bluetooth သည် အနီးကပ်စက်များ ချိတ်ရန် အသုံးများသည်။

2.2 Choosing a connection

Transfer speed/volume depends on bandwidth, signal strength, distance, interference, number of users, hardware and service plan. Bandwidth is the capacity/rate of data transfer (bps); latency is delay before data arrives. High bandwidth helps large downloads/streaming; low latency matters for gaming/video calls. Wired connections are often stable, fast and less exposed to radio interference but restrict movement and need cabling. Wireless gives mobility and easier installation but may suffer interference, congestion and security risks. Broadband is high-capacity internet access; mobile broadband uses cellular networks; cellular networks connect devices through mobile base stations.

မြန်မာ: Bandwidth သည် တစ်စက္ကန့်အတွင်း ပို့နိုင်သော ဒေတာပမာဏ/နှုန်းဖြစ်ပြီး Latency သည် ဒေတာရောက်ရန် ကြာသောနှောင့်နှေးချိန်ဖြစ်သည်။ Video call နှင့် Online game များတွင် Latency နည်းခြင်း အရေးကြီးသည်။

2.3 Connecting to networks and the Internet

  • Device name: human-readable name on a network.
  • IP address: logical network address used for routing.
  • MAC address: hardware/interface identifier.
  • Cable: physical wired link.
  • Wireless access point: connects Wi-Fi devices to a network.
  • Router: forwards packets between networks.
  • Gateway: connects networks using different systems/protocols.
  • Booster/repeater: extends or strengthens a signal.
  • Server: provides shared resources/services.
  • Browser: accesses web pages; ISP: provides internet access; search engine: finds indexed content; filter software: restricts access to selected content.
မြန်မာ: Router သည် Network မတူသောနေရာများအကြား ဒေတာပို့ပေးသည်။ Access Point သည် Wi-Fi ဖြင့် ချိတ်ဆက်ခွင့်ပေးသည်။ ISP သည် Internet ဝန်ဆောင်မှုပေးသူဖြစ်ပြီး Search engine သည် ဝဘ်အချက်အလက်များကို ရှာဖွေပေးသည်။

2.4 LAN and client-server benefits

Peer-to-peer: computers share resources directly; simple and low-cost for small groups but harder to manage centrally. Client-server: clients request services from dedicated servers; centralised control, user permissions, backup, software and storage, but server failure can affect many users and administration costs more. LAN benefits include shared printers/peripherals, files, internet access, communication, media streaming and flexible access. Roaming profiles allow users to access their settings from different computers.

မြန်မာ: Peer-to-peer တွင် ကွန်ပျူတာများ အချင်းချင်း တိုက်ရိုက်မျှဝေသည်။ Client-server တွင် Server က အချက်အလက်နှင့် ဝန်ဆောင်မှုများကို ဗဟိုမှ စီမံပေးသည်။ ကျောင်းတွင် User permission နှင့် Backup ကို ဗဟိုမှ ထိန်းချုပ်နိုင်ခြင်းသည် Client-server ၏ အားသာချက်ဖြစ်သည်။

2.5 Network security

Use unique logins and strong passwords, firewalls, WPA2/WPA3 (older WEP is weak), encryption, VPNs, file access rights, transaction logs and backups. A VPN creates an encrypted tunnel over another network. Access rights limit who can view/edit files. Transaction logs record activity for auditing. Backups support recovery after loss or attack. Choose layered security based on the threat and context.

မြန်မာ: Network လုံခြုံရေးအတွက် Password, Firewall, Encryption, VPN, File permission, Log နှင့် Backup တို့ကို ပေါင်းစပ်သုံးပါ။ WEP သည် ဟောင်းနွမ်းပြီး အားနည်းသောကြောင့် WPA2/WPA3 ကို ပိုမိုရွေးချယ်သင့်သည်။
Deeper understanding, examples & exam application

Network size and purpose

A PAN connects an individual's nearby devices, such as a phone and wireless earbuds. A LAN connects devices in a limited location such as a school building. A WAN connects networks over a large geographical area; the Internet is the best-known example of a global network of networks. Tethering shares a phone's mobile data connection with another device.

Bandwidth, throughput and latency

Bandwidth describes the maximum capacity of a connection; actual throughput is the data rate achieved in practice. Latency is the delay between sending and receiving data. A high-bandwidth connection is useful for large downloads and multiple video streams. Low latency is especially important for interactive gaming and video calls. Signal interference, distance, congestion and the number of users can reduce performance.

Peer-to-peer or client-server?

Peer-to-peer can be appropriate for a small temporary group because it is inexpensive and simple to set up. However, management, security and backup may be inconsistent. Client-server is usually easier to administer in a growing school or organisation because accounts, permissions, files and backups can be managed centrally. The organisation must budget for server hardware, maintenance and skilled administration, and plan for server failure.

PAN သည် လူတစ်ဦး၏ အနီးအနားရှိ စက်များကို ချိတ်ဆက်ခြင်း၊ LAN သည် ကျောင်း/ရုံးကဲ့သို့ နေရာတစ်ခုအတွင်း ချိတ်ဆက်ခြင်း၊ WAN သည် ဝေးလံသော နေရာများရှိ Network များကို ချိတ်ဆက်ခြင်းဖြစ်သည်။ Bandwidth သည် ချိတ်ဆက်မှု၏ ဒေတာပို့နိုင်စွမ်း၊ Throughput သည် လက်တွေ့ရရှိသော ဒေတာပို့နှုန်း၊ Latency သည် ဒေတာပို့/လက်ခံရာတွင် ကြာသောအချိန်ဖြစ်သည်။ အဖွဲ့အစည်းကြီးထွားလာပါက ဗဟိုမှ Permission၊ Backup နှင့် User account စီမံနိုင်သော Client-server သည် ပိုသင့်လျော်နိုင်သည်။
TOPIC 3

Operating Online · အွန်လိုင်းအသုံးပြုမှု

3.1 Risks and protection of data

Risks include unauthorised access, malware damage, accidental deletion and personal-data theft. Phishing uses deceptive messages/sites to trick users into revealing information. Pharming redirects users to fraudulent websites, often without them noticing. Protection: firewall, encryption, strong passwords/PINs, biometrics, CAPTCHA, security questions, anti-malware/virus/adware/spyware, access rights, secure HTTPS sites, careful handling of links/attachments and regular backups. Online payments may use bank cards, contactless NFC or third-party payment services; protection can include encryption, authentication, tokenisation, fraud monitoring and transaction alerts.

မြန်မာ: Phishing သည် အတုအယောင် Email/Website ဖြင့် Password ရယူရန် လှည့်စားခြင်းဖြစ်သည်။ Pharming သည် မှန်ကန်သော Website လိပ်စာထည့်သော်လည်း အတု Website သို့ လမ်းကြောင်းပြောင်းစေခြင်းဖြစ်သည်။ HTTPS, 2-step verification, Backup နှင့် သံသယရှိသော Link မနှိပ်ခြင်းတို့ဖြင့် ကာကွယ်ပါ။

3.2 Impact on individuals

Internet creates jobs and changes job roles/skills; some jobs may be lost through automation. It supports collaboration, remote/flexible/mobile work, access to information, online learning and entertainment. Negative social impacts can include reduced face-to-face interaction, cyberbullying, excessive screen time and reduced physical activity. Stay safe by protecting personal information, using privacy settings, reporting abuse, checking contacts and balancing screen time.

မြန်မာ: Internet ကြောင့် အလုပ်အကိုင်အသစ်များနှင့် အိမ်မှအလုပ်လုပ်နိုင်မှု တိုးလာနိုင်သည်။ တစ်ဖက်တွင် Cyberbullying, မျက်နှာချင်းဆိုင်ဆက်ဆံမှု လျော့နည်းခြင်းနှင့် ကိုယ်လက်လှုပ်ရှားမှုနည်းခြင်း ဖြစ်နိုင်သည်။

3.3 Working from home

Digital devices, broadband, collaboration tools and cloud services enable remote work. Benefits for individuals: less commuting, flexibility and improved work-life balance. Drawbacks: isolation, distractions, blurred work/home boundaries and dependence on reliable internet. Organisations may reduce office costs and recruit widely, but may face security, communication, monitoring and team-coordination challenges.

3.4 Impact on organisations

Positive: faster communication, global markets/customers, wider recruitment, online sales and improved information management. Negative: hacking, data breaches, downtime, privacy/legal responsibilities and increased competition. Organisations need security policies, staff training, backups and continuity plans.

3.5 Impact on society and digital divide

Always-available networks change access to services and socialising. The digital divide is the gap between people with good access/skills and those without. Causes include income, geography, infrastructure, disability, age and education. Consequences include unequal access to jobs, education, healthcare and public services. Communities with limited access may be excluded from opportunities.

မြန်မာ: Digital Divide ဆိုသည်မှာ Internet/စက်ပစ္စည်း/ဒစ်ဂျစ်တယ်ကျွမ်းကျင်မှု ရရှိသူနှင့် မရရှိသူတို့အကြား ကွာဟချက်ဖြစ်သည်။ ဝင်ငွေ၊ နေရာဒေသ၊ အခြေခံအဆောက်အအုံနှင့် ပညာရေးတို့ကြောင့် ဖြစ်နိုင်သည်။

3.6–3.7 Online communities and safe use

Types include social networks, online gaming, workspaces, VLEs, wikis, forums, video-sharing, blogs and social bookmarking. They support communication, collaboration, learning and shared interests globally. Users should follow acceptable-use policies, respect others, avoid cyberbullying, protect identity/location and remember that online identities may be misrepresented.

3.8 Legal, ethical, environmental and health issues

Data protection rules govern how personal data is collected, stored and used; individuals have rights over their data. Copyright protects creators' work; permission/licensing and acknowledgement may be required. Plagiarism is presenting another person's work as your own, including copying or paraphrasing without credit. Digital monitoring can track movement/communications, raising privacy concerns. Sustainability issues include energy use, e-waste and resource extraction; mitigate through repair, reuse, recycling and energy-efficient devices. Health risks include eye strain, repetitive strain injury, back/neck pain and sedentary behaviour; use ergonomic posture, breaks and suitable lighting.

မြန်မာ: Copyright သည် ဖန်တီးသူ၏ လက်ရာကို ကာကွယ်သည်။ Plagiarism သည် အခြားသူ၏ အလုပ်ကို ကိုယ့်အလုပ်ကဲ့သို့ တင်ပြခြင်းဖြစ်သည်။ E-waste ကို စနစ်တကျ ပြန်လည်အသုံးချ/စွန့်ပစ်ပြီး မျက်စိပင်ပန်းမှုနှင့် ကိုယ်ဟန်အနေအထားပြဿနာများကို အနားယူခြင်း၊ Ergonomic နည်းလမ်းများဖြင့် လျှော့ချပါ။

3.9 Finding and evaluating online information

Use suitable sources and search operators/keywords. Evaluate information using accuracy (is it correct?), age (is it current?), relevance (does it answer the question?), reliability (is the source trustworthy?) and bias (does it present one-sided views?). Cite sources and obtain permission where needed. Paraphrasing does not remove the need to acknowledge the source.

မြန်မာ: Online information ကို အသုံးပြုမီ မှန်ကန်မှု၊ နောက်ဆုံးပြင်ဆင်ထားသည့်အချိန်၊ မေးခွန်းနှင့် သက်ဆိုင်မှု၊ ယုံကြည်စိတ်ချရမှုနှင့် ဘက်လိုက်မှု ရှိ/မရှိ စစ်ဆေးပါ။ ကိုးကားချက် ထည့်ရန် မမေ့ပါနှင့်။
Deeper understanding, examples & exam application

Threats are not all the same

Phishing relies on tricking a person through a fake message or website. Pharming redirects a user to a fraudulent destination. Malware is malicious software; examples include viruses, worms, spyware and ransomware. A firewall filters network traffic according to rules. Anti-malware software detects or removes malicious code. Encryption makes data unreadable to people who do not have the correct key. Backups help restore data but do not prevent an attack in the first place.

Privacy, ethics and law

Personal data should be collected and used fairly, securely and for a clear purpose. Copyright protects original creative work; a user may need permission or an appropriate licence before copying or distributing it. Plagiarism is presenting another person's work as your own. Ethical use also means respecting privacy, avoiding cyberbullying and not sharing another person's images or details without permission.

Evaluate online information

Check the author or organisation, publication date, evidence, references, purpose and possible bias. Compare important claims with independent reliable sources. A professional-looking page is not automatically accurate. When using information in an assignment, record the source and acknowledge it even when you paraphrase.

Phishing သည် လူကို လှည့်စား၍ ကိုယ်ရေးအချက်အလက် ထည့်စေခြင်းဖြစ်ပြီး Pharming သည် အသုံးပြုသူကို အတု Website သို့ လမ်းကြောင်းပြောင်းစေခြင်းဖြစ်သည်။ Malware သည် အန္တရာယ်ရှိသော Software အမျိုးအစားဖြစ်သည်။ Firewall သည် Network traffic ကို စစ်ထုတ်ပြီး Encryption သည် မှန်ကန်သော Key မရှိသူ မဖတ်နိုင်အောင် ဒေတာကို ကုဒ်ပြောင်းသည်။ Backup သည် ဒေတာပျောက်ဆုံးပြီးနောက် ပြန်လည်ရယူရန် ကူညီသော်လည်း တိုက်ခိုက်မှုကို တားဆီးပေးသည့် နည်းလမ်းမဟုတ်ပါ။ Online အချက်အလက်ကို အသုံးပြုရာတွင် ရေးသားသူ၊ ရက်စွဲ၊ အထောက်အထား၊ ရည်ရွယ်ချက်နှင့် ဘက်လိုက်မှုကို စစ်ဆေးပါ။
TOPIC 4

Online Goods and Services · အွန်လိုင်းကုန်ပစ္စည်းနှင့် ဝန်ဆောင်မှုများ

4.1 Types of online services

Shopping: product catalogue, basket, checkout and secure payment. Booking: travel, leisure and entertainment reservations. Banking: balances, transfers, bill payment and statements. Education: VLE, online support, training courses and remote access. Other services include gaming, news/information, auctions, streaming, on-demand entertainment and downloads.

မြန်မာ: Online shopping တွင် Product catalogue, Shopping basket, Checkout နှင့် Secure payment ပါဝင်သည်။ Booking system သည် ခရီးသွား/ဖျော်ဖြေရေး ကြိုတင်မှာယူရန်၊ VLE သည် Online သင်ယူရန် အသုံးပြုသည်။

4.2 Impact of online services

Individuals can shop/learn/bank at any time, compare prices and access a wider choice. Drawbacks include delivery delays, inability to inspect items physically, fraud, privacy risks and reduced local high-street activity. Organisations can reach global customers, operate 24/7 and collect useful sales data, but face cyber risks, delivery/returns costs and competition. Transactional data includes items viewed/bought, time, location and payment details. Cookies store information in a browser; tracking records user interactions. Targeted marketing uses collected data to show relevant adverts. Personalisation adapts recommendations/content to a user.

မြန်မာ: Online service များကြောင့် အချိန်မရွေး ဝယ်ယူ/ဘဏ်လုပ်ငန်း/သင်ယူနိုင်သည်။ သို့သော် ပစ္စည်းကို မကိုင်ကြည့်နိုင်ခြင်း၊ လိမ်လည်မှုနှင့် ကိုယ်ရေးအချက်အလက်ပေါက်ကြားမှု ဖြစ်နိုင်သည်။ Cookies သည် Browser ထဲတွင် အချက်အလက်အချို့ သိမ်းဆည်းပြီး Targeted advertising အတွက် အသုံးပြုနိုင်သည်။

4.3 Cloud and online software

Cloud computing provides hosted applications and storage over the internet. Benefits: access from different devices/locations, collaboration, scalability and reduced local installation/maintenance. Drawbacks: dependence on internet/provider, recurring costs, privacy/security concerns and possible outages. Hosted applications run on provider systems and are accessed online; locally installed applications run on the user's device. Online storage supports sharing/synchronisation and off-site access; local storage can work offline and gives direct control but may be lost/damaged with the device. A sensible approach may combine cloud and local backups.

မြန်မာ: Cloud service သည် Internet မှတစ်ဆင့် Software နှင့် Storage ကို အသုံးပြုခြင်းဖြစ်သည်။ မည်သည့်နေရာမှမဆို ဝင်ရောက်နိုင်ပြီး ပူးပေါင်းလုပ်ဆောင်ရလွယ်သော်လည်း Internet နှင့် Service provider အပေါ် မှီခိုရသည်။ Local storage သည် Offline သုံးနိုင်သော်လည်း စက်ပျက်လျှင် ဒေတာဆုံးရှုံးနိုင်သည်။

Key exam vocabulary

Catalogue = product list; basket = selected items before checkout; checkout = final order/payment process; transaction = recorded exchange/payment; cookie = small browser-stored data; tracking = recording activity; targeted marketing = adverts selected using user data; personalisation = tailoring content/services; hosted application = software run on remote servers.

Deeper understanding, examples & exam application

Typical online transaction

A customer browses a catalogue, selects products, adds them to a basket, enters delivery details, reviews the order, chooses a payment method and confirms checkout. The website or payment provider processes the payment and sends confirmation. A secure service should protect personal and payment information, authenticate the customer where appropriate and provide a clear transaction record.

Cookies, tracking and personalisation

A cookie is a small piece of data stored by a browser for a website. Some cookies support essential functions such as keeping a session active or remembering a basket. Other technologies may track activity across pages or services. Personalisation adapts a service to a user, while targeted marketing selects adverts using information about interests or activity. Users should understand privacy settings and consent choices.

Cloud service decision

Cloud storage is useful when files must be accessed from different locations or shared by a team. Local storage can be more convenient when internet access is unreliable or when a user needs direct control. A hybrid approach can combine local working copies with encrypted cloud or external backups. Organisations should consider access controls, provider reliability, data location, recurring fees and recovery arrangements.

Online Shopping လုပ်ငန်းစဉ်တွင် ပစ္စည်းစာရင်းကြည့်ခြင်း၊ Basket ထဲထည့်ခြင်း၊ Delivery အချက်အလက်ဖြည့်ခြင်း၊ Payment ရွေးခြင်းနှင့် Checkout အတည်ပြုခြင်းတို့ ပါဝင်သည်။ Cookie သည် Website က Browser ထဲတွင် သိမ်းဆည်းသော ဒေတာအနည်းငယ်ဖြစ်ပြီး Session/Basket မှတ်မိစေရန် သို့မဟုတ် Tracking အတွက် အသုံးပြုနိုင်သည်။ Cloud သည် နေရာမရွေးဝင်ရောက်/မျှဝေရန် အဆင်ပြေသော်လည်း Internet နှင့် Provider အပေါ် မှီခိုရသည်။ Local storage သည် Offline အသုံးပြုနိုင်သော်လည်း စက်ပျက်ခြင်း/ပျောက်ဆုံးခြင်းအန္တရာယ်ရှိသည်။
Exam tip / စာမေးပွဲဖြေနည်း: “State” = short fact. “Describe” = give a feature and detail. “Explain” = make a point and show why/how it matters. “Compare” = discuss both sides using direct contrasts. “Justify” = choose an option and link reasons to the scenario. For a 6-mark response, aim for several distinct, developed points rather than repeating one idea.

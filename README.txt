FILES

HOW TO OPEN
1. Extract the ZIP.
2. Put logo1.png beside the three HTML files.
3. Open index.html in Chrome, Edge or Firefox.
4. Use the links inside the website to open practice sets and full papers.

- Refined premium gold and pearl-white responsive interface

- Labelled diagrams, flow charts and comparison tables
